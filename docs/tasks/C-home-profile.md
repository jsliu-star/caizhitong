## C2. 共享档案页 `/profile`

这一页要回答一个问题：**「三个 Tab 是一个有记忆的系统，还是三个独立小工具？」**

### 页面内容

1. **画像概览**：风险类型（`RISK_META[riskType].label`）、综合得分（`Gauge`）、
   四维雷达（承受能力/风险意愿/投资期限/金融知识 —— 数据来自 `profile.riskScore` 与规划师，
   若档案里没有分维数据就只显示已有字段，**不要编**）
2. **档案里已有什么**：年龄段、风险等级、知识等级与积分、遇到过的骗局类型、
   负债真实年化、应急金月数、目标列表 —— 有就显示，没有就显示「还没测，去规划师测一下 →」
3. **★ 联动说明（本页的灵魂）**：一个表格或卡片列表，**根据档案实际内容动态生成**，
   说明「因为档案里有 X，所以另外两个 Tab 为你做了 Y」。规则示例：

| 档案里的事实 | 联动效果 |
|---|---|
| `riskType` 是 growth / aggressive | 安全盾会重点提示「高收益话术」——这种偏好最容易被钓走 |
| `knowledge.weakTerms` 非空 | 翻译官会把这些术语置顶；规划师讲配置时会先解释再给比例 |
| `encountered` 含 `vp-stock-recommendation` | 翻译官推送「为什么免费荐股群一定有问题」；规划师在权益类追加提示 |
| `debtApr` > 0.1 | 全站提示「先还掉年化 X% 的债，再谈理财」 |
| `emergencyMonths` 已算出 | 规划师的配置框架会据此调整活钱比例 |
| `ageBand` 是 60+ | 全站字号放大、术语进一步简化，安全盾优先展示针对老年人的骗局 |

**只展示档案里真实存在的字段触发的联动**，不要把没触发的也列出来假装有。

4. **体验模式**：一键载入 `DEMO_PROFILE`（`lib/profile.ts` 已导出），
   让上面的联动效果立刻可见。按钮文案写清楚这是演示数据
5. **清除档案**：`clearProfile()` + 二次确认
6. **隐私声明**：档案只存在你自己的浏览器里（localStorage），不上传、不建集中式用户库。
   这是金融场景下的刻意选择 —— **这句话要显眼，它是加分项**

### 技术注意

- `/profile` 必须是客户端组件（要读 localStorage），首屏加载前显示骨架，不要闪烁
- localStorage 读写全部包 try/catch（隐私模式会抛异常）
- 不要在这一页写入档案，只读 + 体验模式 + 清除

5. **`components/viz` 的 Radar 在 4 轴时左右轴标签被裁掉 —— `/plan` 上正在发生（已实测）**

   成因：4 轴时 E/W 两个标签落在 `x = c ± (R+20) = c ± (c-14)`，即紧贴 viewBox 边缘，
   再叠加 `text-anchor: start/end`，整段文字被推到画布外；SVG 默认 `overflow: hidden`，于是被切。
   **它与视口宽度无关**——切的是 SVG 自身的盒子，所以桌面端也一样切。

   headless Chrome 实测（1440×900，非大字号，`/plan` 完成测评后）：
   | 元素 | 文字实际横跨 | 所在 SVG 盒子 | 结果 |
   |---|---|---|---|
   | 雷达轴标签「风险意愿」 | 624..672 | 378..638 | 右侧被切 **34px** |
   | 雷达轴标签「金融知识」 | 344..392 | 378..638 | 左侧被切 **34px** |

   375px 下同样被切（「风险意愿」right=381 / 「金融知识」left=-6）。
   **页面不会因此横向滚动**（`scrollWidth == innerWidth`），纯粹是标签看不全。

   我在 `/profile` 的绕法（**没有改共享文件**）：容器加 `[&_svg]:overflow-visible` +
   `px-8 sm:px-14` 留出左右余量，四个标签就都完整了。`/plan` 与 `components/plan/**` 归属不是我，
   **没有动**。修法同上一行，一行 class 的事，请所有者或人工决定。
